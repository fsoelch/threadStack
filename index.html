Willkommen bei ThreadStack

ThreadStack hilft Ihnen, Meeting-Themen strukturiert zu verwalten — vom ersten Gedanken bis zum erledigten Ergebnis. Alles dreht sich um drei Kernkonzepte:

📅 Meetings
Wiederkehrende oder einmalige Termine mit Themen, die Sie von Mal zu Mal weiterführen.
💬 Themen
Diskussionspunkte innerhalb eines Meetings — offen, schlafend oder erledigt.
✅ Todos
Aufgaben aus Meetings, mit optionalem Fälligkeitsdatum und Meeting-Verknüpfung.
📚 Stack
Fokus-Werkzeug: legen Sie ein Thema auf den Stack, um es im aktuellen Kontext zu bearbeiten.

Typischer Arbeitsablauf

  1. Meeting anlegen (Sidebar → + Neues Meeting)
  2. Themen zum Meeting hinzufügen, sobald sie anfallen
  3. Im Meeting selbst Ergebnisse eintragen und Themen erledigen
  4. Offene Punkte schlafen legen oder als Todo herauslösen
  5. Den Stack nutzen, um sich auf ein Thema zu konzentrieren
Tipp: Die Seitenleiste zeigt alle Meetings und Ihre Todo-Liste. Klicken Sie auf ein Meeting, um dessen Themen zu sehen.

Meetings

Meetings sind der Rahmen, in dem Themen gelebt werden. Sie können einmalig oder wiederkehrend sein.

Meeting anlegen

  • Klicken Sie in der Sidebar auf + Neues Meeting oder den gleichnamigen Button im leeren Hauptbereich.
  • Vergeben Sie einen Titel, optional eine Beschreibung, Teilnehmer und eine Farbe.
  • Für wiederkehrende Termine aktivieren Sie den Schalter und wählen das Muster (täglich, wöchentlich, monatlich).

Nächsten Termin vorziehen

Bei wiederkehrenden Meetings erscheint oben rechts der Button Nächster Termin. Ein Klick setzt das Datum auf den nächsten geplanten Termin und archiviert erledigte Themen sauber.

Meetings sortieren

In der Sidebar können Sie Meetings per Drag & Drop in Ihre bevorzugte Reihenfolge bringen — einfach am Meeting-Eintrag ziehen.

Farbe: Jedes Meeting hat eine Akzentfarbe, die als farbiger Balken links in der Meeting-Ansicht erscheint. So erkennen Sie auf einen Blick, in welchem Meeting Sie sich befinden.

Themen

Themen sind die Diskussionspunkte eines Meetings. Sie durchlaufen drei Zustände: Offen → Erledigt oder Offen → Schlafend → Offen.

Thema hinzufügen

  • Im Meeting-Bereich oben rechts: + Thema
  • Geben Sie Titel und optionale Details ein. Details unterstützen Formatierung (fett, kursiv, Farben, Listen).

Thema erledigen

Klicken Sie auf Erledigt bei einem Thema. Es öffnet sich ein Dialog für ein optionales Ergebnis — was wurde besprochen oder entschieden? Das Ergebnis wird dauerhaft beim Thema gespeichert.

Thema schlafen legen

Über das ⋯-Menü des Themas wählen Sie Schlafen bis … und ein Datum. Das Thema verschwindet aus der offenen Liste und erscheint am gewählten Tag automatisch wieder.

Reihenfolge ändern

Themen lassen sich per Drag & Drop innerhalb eines Meetings umsortieren. Der Anfasser (⠿) erscheint links beim Hover über ein Thema. Die Reihenfolge wird sofort gespeichert.

Thema teilen

Ein Thema kann in mehreren Meetings gleichzeitig erscheinen (In weiterem Meeting teilen im ⋯-Menü). Änderungen sind in allen Meetings sichtbar.

Schlafend: Themen, die noch nicht besprochen werden sollen, schlafen legen — so halten Sie die offene Liste übersichtlich.

Todos

Todos sind persönliche Aufgaben, die optional einem Meeting zugeordnet sein können. Sie finden alle Todos in der Sidebar unter Todos.

Todo erstellen

  • In der Sidebar: Klick auf Todos, dann + Todo
  • Aus einem Meeting-Thema heraus: ⋯ → Als Todo hinzufügen

Fälligkeitsdatum

Jedes Todo kann ein Fälligkeitsdatum haben. In der Todo-Liste werden Aufgaben zuerst nach Fälligkeit sortiert (früheste oben), danach manuell sortierbare Aufgaben.

  • Grün — fällig in ≥ 2 Tagen
  • Gelb — fällig morgen oder heute
  • Rot — überfällig

Todo erledigen

Klicken Sie auf den grünen Haken oder Erledigt neben dem Todo. Optional können Sie ein Ergebnis eintragen.

Todo schlafen legen

Wie bei Themen: ⋯ → Schlafen bis … — das Todo verschwindet bis zum gewählten Tag aus der aktiven Liste.

Stack

Der Stack ist ein Fokus-Werkzeug: Sie legen ein Thema oder Todo auf den Stack, arbeiten daran, und poppen es danach wieder ab. So behalten Sie den Überblick, auch wenn Sie zwischen Themen wechseln.

Thema oder Todo pushen

  • Bei jedem offenen Thema: 📚-Button → Stack-Push-Dialog öffnet sich
  • Tragen Sie einen Nächsten Schritt ein (Pflichtfeld) — was wollen Sie jetzt konkret tun?
  • Wählen Sie optional Priorität und Notiz

Stack-Panel

Das Stack-Panel erscheint unten rechts (blauer Layers-Button). Es zeigt den aktuellen Stack-Frame — was gerade oben liegt.

Thema poppen (abschließen)

Im Stack-Panel: Pop-Button. Es öffnet sich ein Dialog, in dem Sie wählen:

  • Erledigt — Thema wird als erledigt markiert
  • Verschoben — zurück in die offene Liste
  • Verworfen — Thema wird verworfen (bleibt aber im Stack-Verlauf)
  • Wiederaufgenommen — bleibt offen, Stack-Frame wird geschlossen

Stack-Verlauf

In der Sidebar unter Stack-Verlauf sehen Sie alle vergangenen Stack-Frames mit ihren Ergebnissen.

Tipp: Nutzen Sie den Stack wie einen Zurück-Button im Browser — push bei Unterbrechungen, pop wenn Sie fertig sind.

Kontakte

Kontakte sind Personen, die Sie in ThreadStack verwalten können — z. B. regelmäßige Meeting-Teilnehmer.

Kontakt anlegen

  • Sidebar → Kontakte → + Kontakt
  • Felder: Name (Pflicht), Rolle, E-Mail, Beschreibung (mit Formatierung)

Kontakte verknüpfen

Über das Theme-System können Kontakte mit Themen verknüpft werden. Die Suche (Lupe oben in der Kontaktliste) filtert nach Name, Rolle und E-Mail.

E-Mail-Verknüpfung

Ein Klick auf eine E-Mail-Adresse öffnet Ihr Standard-E-Mail-Programm mit dem Empfänger vorausgefüllt.

Textformatierung

Alle Textfelder (Beschreibung, Details, Ergebnis) unterstützen einen Rich-Text-Editor mit folgenden Werkzeugen:

B Fett
Text markieren, dann B klicken oder Strg+B
I Kursiv
Text markieren, dann I klicken oder Strg+I
U Unterstrichen
Text markieren, dann U klicken oder Strg+U
• Liste
Fügt eine Aufzählungsliste an der Cursorposition ein.
🔗 Link
Text markieren → Link klicken → URL eingeben. Links öffnen in einem neuen Tab.
📊 Tabelle
Fügt eine Tabelle ein. Zeilen- und Spaltenzahl wählen.
A Textfarbe
Text markieren → A-Button → Farbe wählen. ✕ entfernt die Farbe wieder.
Hinweis: Die Formatierung wird in der Web-App und in der iOS/macOS-App vollständig dargestellt, einschließlich Farben, fett und kursiv.
